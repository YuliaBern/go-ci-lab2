# Lab 2 — Go Modules & GitHub Actions

Проєкт виконано в межах лабораторної роботи №2 з дисципліни "Інструментальні засоби розробки програмного забезпечення".

## Тема роботи
Управління залежностями в Go та автоматизація перевірок через GitHub Actions.

## Мета роботи
- навчитися працювати із зовнішніми залежностями в Go;
- дослідити механізм Go Modules;
- налаштувати CI-конвеєр через GitHub Actions;
- автоматизувати перевірку коду.


## Run project

```bash
go run ./cmd/app
```

## Run tests

```bash
make test
```

## Run lint

```bash
make lint
```
